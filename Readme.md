## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/ankitparmanik65-crypto/Portfolio.git
```

Open the project folder:

```bash
cd Portfolio
```

Then open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for local development.

## 🚀 Deployment

This portfolio is deployed using **Vercel**.

Whenever changes are pushed to the `main` branch, the connected Vercel project can automatically create a new deployment.
